# Decision log: branch `feat/vision-transform`

Pixel (camera above the table) -> x / y in Fairino `base_link`, for the control loop. Replaces the scratch tool
`pix2table` (not in git; lab test with 4 ArUco tags: 5-7 mm). Robot facts (frames, tool geometry, gripper) live in the
decision log of branch `feat/robot-motion-gripper`. Units: metres / radians in code, mm only in logs.

| V-14 | Fit quality per tag | Per tag `err_mm` (residual) + `drop_rms_mm` (rms of the OTHER tags without this one, 6+ tags); `suspect` = tag whose removal makes the rest fit (rms > 2 mm, removal halves it, 3x clearer than any other tag), else None. Printed centring target (35 mm ring + crosshair) not used for now | User: the camera detects the tags easily, so repeat the robot side. | V-17 | Lens distortion (plan B, sim) | Homography + 1 radial lens term k fitted from the same tags (p_u = c + (p_d - c)(1 + k r^2), c = image centre, 1-D search over k + least-squares homography). **Result, 8 tags, 1 mm recording, 0.5 px noise, 200 runs (mean / 95 %, mm): no distortion A 0.86 / 1.56, B 0.99 / 1.76; k1 0.05 A 2.37 / 3.97, B 0.94 / 1.67; k1 0.10 A 4.43 / 7.35, B 0.91 / 1.64; k1 0.10 + k2 0.03 A 4.83, B 0.95; barrel k1 -0.08 A 3.43, B 0.93; k1 0.10 + 2 mm recording A 4.55, B 1.65.** Truth used a different formula and an off-centre optical centre (+20 / -15 px), so B is robust to model mismatch | B beats A by 2.5-5x whenever the lens distorts, costs ~0.1 mm when it does not.
